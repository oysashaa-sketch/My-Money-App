# My Money — персональный финансовый помощник (версия 0.3)

Локальное приложение под телефон: операции, категории, цели и желания, обязательства, займы, проверка покупок и резервные копии.

## Что уже работает

- Добавление доходов, расходов, процентов по долгам, погашений кредитов, резервирования накоплений.
- Остаток на карте по ручным операциям; ближайшие запланированные платежи; следующая зарплата по графику 5-го/20-го (с переносом выходного на предшествующую пятницу).
- Месячные бюджеты всех 15 категорий: план, факт, остаток и процент использования. Отдельный ожидаемый расход для прогноза. Старые лимиты продуктов и такси сохранены; общий бюджет транспорта заменяет прежний лимит только такси.
- Категория **«Продукты»** для продуктов и доставки готовой еды. Сервис/канал — отдельные метки: доставка, маркетплейс и т. п.
- Цели и желания, привязка резервов к целям.
- График платежей: еженедельные, каждые 14 дней, ежемесячные, разовые, раз в два месяца.
- Платежи по кредиткам и Сплиту не дублируют расходы на уже купленные товары.
- Проверка покупки по текущему остатку, прогнозу и бюджету категории, с учётом срочности и доставки; статистика внесённых доставок продуктов за 7/30 дней. Это **правила и расчёты, а не чат с ИИ**.
- Экспорт/импорт полной копии данных JSON и истории CSV.
- Работа без интернета после первоначальной загрузки на совместимом браузере с Service Worker.

## Важно: ограничение прототипа

Это **ранняя версия** для тестирования поведения и арифметики, а не готовый финансовый советник. Она не подключается к банкам, не узнаёт автоматически о новых платежах, не гарантирует сохранность данных без резервных копий, не рассчитывает проценты кредиток автоматически и не умеет уведомлять в фоне. Для кредитки доступен единый платёж с необязательным новым остатком банка. Без него остаток требует сверки; точная доля процентов не вычисляется. Старые записи процентов сохраняются. Приложение не блокирует покупку физически.

При возврате денег партнёру за аренду вноси только одну операцию за аренду, а не две. Если партнёр оплатил за тебя, запланируй долг перед ним как обязательство, не удваивая категорию «Жильё».

Справочная функция «После ближайших платежей» — это не полноценный располагаемый остаток: ещё не совершённые переменные траты и все платежи после ближайшей зарплаты туда не включены. Большие платежи сразу после зарплаты подсвечиваются отдельно.

## Самый простой путь для новичка: бесплатно с iPhone

1. **Код приложения**: загрузить содержимое *этой* папки (включая `icons`) в **публичный** репозиторий GitHub, например `my-money-app`. В этой папке нет личных финансовых данных.
2. В репозитории открыть **Settings → Pages**, раздел **Build and deployment → Deploy from a branch**, выбрать `main` / `(root)` и нажать Save.
3. Дождаться появления адреса вида `https://имя.github.io/my-money-app/`. Открой его с iPhone в Safari. Для установки на главный экран: **Поделиться → На экран «Домой»** (или «Добавить на экран Домой», название зависит от версии iOS).
4. **Уже из иконки на главном экране** открыть «Настройки → Восстановить из JSON» и выбрать твой отдельный частный файл `my-money-private-start.json`, если он у тебя есть. Этот файл **НИ В КОЕМ СЛУЧАЕ НЕ ЗАГРУЖАТЬ НА GITHUB**.
5. В «Запланированных платежах» скорректировать ориентировочные даты платежей, сумму каждого платежа в Сплит и свой актуальный календарь. Зарплату 5-го и 20-го добавляй вручную только после получения.
6. В «Настройках» регулярно сохранять JSON-резервную копию в «Файлы» iPhone — хотя бы раз в неделю и **обязательно перед обновлением приложения**.

Место хранения — локальное хранилище браузера/веб-приложения конкретного iPhone. Смена телефона, очистка данных Safari, некоторые системные очистки и удаление приложения могут привести к потере данных. Локальные данные не зашифрованы отдельным паролем; человеку с доступом к разблокированному устройству и профилю браузера они потенциально доступны.

### Почему нужны два разных файла

- `my-money-v01.zip` — только код и дизайн; безопасно размещать на публичном хостинге, поскольку нет никаких персональных цифр.
- `my-money-private-start.json` — твои исходные финансовые данные и ориентировочные даты; хранить только в частных файлах и импортировать в приложение. Нельзя добавлять в публичный репозиторий.

Если захочешь позже перенести работу в Codex: открой созданный репозиторий в Codex, попроси внести одну конкретную поправку, протестируй, опубликуй изменения через GitHub, затем **перед обновлением** сделай резервную копию. Не вставляй свой приватный JSON в репозиторий и не проси Codex записывать свои финансы в исходники.

## Подсказки по ручному вводу

- **Самокат / Яндекс Лавка**: расход → категория «Продукты» → сервис → канал «Доставка».
- **Ozon: энзимная пудра**: расход → «Красота» → канал «Маркетплейс».
- **Ozon: салфетки для стирки**: расход → «Дом и быт» → канал «Маркетплейс».
- **Такси**: расход → «Транспорт» → канал «Такси». Поезда/метро остаются в «Транспорте», но не попадают в лимит такси.
- **Сплит: купленная вещь**: новая покупка в Сплит → способ оплаты «В кредит / Сплит», выбери задолженность (если известен начальный остаток). Это влияет на статистику покупок, но не вычитает деньги с карты сейчас.
- **Сплит: очередной платёж**: вкладка «Запланированные платежи» → у платежа «Оплачено». Уменьшит карту и, если указан конкретный долг, его остаток, без второго расхода на вещь.
- **Кредитка: платёж**: «Мои долги» → «Внести платёж» → фактическая сумма, дата и при наличии новый остаток банка. Выбери конкретный запланированный платёж для связи с календарём. Ранее внесённые проценты повторно вводить не нужно. Отдельная операция процентов остаётся доступной для явных начислений после сверки.
- **Отложить часть зарплаты**: «Отложить деньги». Накопление пока виртуально зарезервировано внутри того же баланса карты, физического банковского перевода нет.

## Как запустить на ноутбуке для теста

Файл `index.html` можно открыть в браузере, но сохранение и автономный режим по адресу `file://` зависят от браузера и не подходят для надёжного постоянного использования. Для мобильного использования предпочтителен HTTPS-хостинг, как описано выше.

## Следующее обновление: ежедневный помощник (Draft)

Единый сценарий платежей по кредиткам и Сплиту, частичные оплаты, финансирование существующего крупного платежа несколькими поступлениями, редактируемые предложения бюджета и упрощённая главная подготовлены в новой ветке от main. Весь бюджет перенесён в «Мой бюджет», календарь называется «Запланированные платежи», операции — «История операций». Формат JSON и ключ хранения остаются прежними. Новые лимиты принимаются только по явному действию пользователя.

[Отчёт, ограничения и безопасная проверка на iPhone](ASSISTANT-REPORT.md). Все проверки: `node tests/planner.test.cjs` и `node tests/assistant.test.cjs` — 76 тестов. Изменения не опубликованы.
